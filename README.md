# CC 生日快樂 🎂

為 CC 的 9 月 7 日生日製作的 3D 祝福網頁（繁體中文），手機、電腦都能開。

## 開啟方式

直接用瀏覽器打開 `index.html` 即可（需要連網，Three.js 從 CDN 載入）。

若要用手機瀏覽，可在電腦上啟動本地伺服器：

```bash
cd cc-birthday
python3 -m http.server 8080
```

然後手機連同一個 Wi-Fi，打開 `http://<電腦的IP>:8080`。

想給她一個永久連結的話，可以把這個資料夾部署到 GitHub Pages、Vercel 或 Netlify。

## 頁面內容

- 🎂 3D 三層生日蛋糕（草莓、奶油、金色「CC」字）
- 🕯️ 五根蠟燭，可以「吹蠟燭許願」再點亮
- 🎆 煙火：自動施放，輕觸畫面或按按鈕也會放
- 💗 點擊畫面會爆出愛心
- 🎈 漂浮氣球、🎊 彩帶、✨ 星空與魔法光塵
- 🎵 WebAudio 合成的生日快樂歌（可開關）
- 📱 支援手機觸控：拖曳旋轉視角、雙指縮放
